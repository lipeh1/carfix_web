支撑体系 横切所有阶段

金额与一致性

  • 全链路整数「分」存储，展示/输入边界换算 fenToYuan / yuanToFen
  • 报价优惠登记 → 质检生成结算单时自动抵扣
  • 增项确认 = 幂等并入明细 + 按明细重算 finalAmount
  • 收款事务内重算，结算单与工单已收金额同步
  • 挂账 = actualAmount − paidAmount，首页与报表口径统一

工程与防护

  • 状态机白名单：非法流转请求返回 400
  • 关键写路径 $transaction：接车/报价/质检/收款/增项
  • 防重：重复交车、重复确认增项均拦截
  • 校验：客户-车辆归属、存在性 404、上传 MIME 双重校验
  • GitHub Actions CI：前后端并行类型检查 + 构建把关
